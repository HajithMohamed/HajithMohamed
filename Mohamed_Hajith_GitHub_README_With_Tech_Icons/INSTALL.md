# Install the GitHub profile README redesign with skill icons

1. Go to https://github.com/HajithMohamed/HajithMohamed
2. Back up your existing README.md.
3. Add/replace **README.md**, **profile-banner-dark.svg**, and **profile-banner-light.svg** in the repository root.
4. Commit changes; check https://github.com/HajithMohamed on desktop/mobile and light/dark GitHub themes.

The language/framework icons are dynamically loaded from https://skillicons.dev/ and need internet access. They are decorative summaries; text labels remain readable if the icon service is unavailable. No profile edits were made automatically.

**Note:** `HTML` and `CSS` appear under *Languages & web fundamentals* rather than being called programming languages. Python, Flutter, Dart, and Azure remain in *Currently learning*.
